# exp2

Flutter experiment 2 - a product catalog app with category panels and product cards.

## Use

```
flutter pub add exp2
```

```dart
import 'package:exp2/exp2.dart';

runApp(const CatalogApp());
```


## Run in VS Code
1. Open this folder in VS Code (File > Open Folder).
2. Open a terminal and run:
   flutter pub get
3. Pick a device (Android phone, emulator, Chrome) from the bottom-right corner.
4. Press F5 or run: flutter run
